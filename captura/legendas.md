# Legendas — Instagram e Telegram (voz da marca Vixeee)

Voz da marca: divertida, popular, animada, "achadinho que você PRECISA ver". Sempre começa com **"Vixeee 🙀"** no Instagram. Nunca usar nome pessoal. Nunca revelar comissão/margem (é interno — não vai em post público).

## Instagram (campo `legenda_ig`)
O link NÃO fica clicável na legenda do IG → sempre chamar **"🔗 Link na bio!"** (a bio redireciona pro Telegram). Estrutura:
- Linha 1: gancho com "Vixeee 🙀" + a dor/desejo ou o preço chocante.
- 1–2 linhas: benefício concreto + prova (nº de vendas, "100% X", etc.).
- Urgência leve (o desconto some).
- `🔗 Link na bio!`
- Linha em branco + 4–5 hashtags (mix de nicho + marca): sempre incluir `#vixeeequebarato` e `#shopeefinds`/`#achadinhos`.

**Exemplo (Creatina, R$39,90, 47% OFF):**
```
Vixeee 🙀 creatina PURA por menos de R$40?!
300g que rendem o mês inteiro de treino 💪
✅ 100% pura · +100 MIL já garantiram
Corre que 47% OFF não dura 😳
🔗 Link na bio!

#achadinhos #creatina #shopeefinds #vixeeequebarato #treino
```

## Telegram (campo `legenda_tg`)
Aqui o link É clicável → colocar o link de afiliado no fim. Curto e direto:
- Linha 1: emoji + PRODUTO em CAIXA + preço (desconto).
- Linha 2: 1 benefício ou prova social.
- Linha 3: `👉 <link de afiliado>`

**Exemplo:**
```
💪 CREATINA PURA 300g — R$39,90 (47% OFF!)
+100 MIL vendas. Some rápido!
👉 https://s.shopee.com.br/XXXX
```

## Regras de qualidade
- Adaptar o gancho ao produto (cozinha, carro, ferramenta…), não repetir a mesma piada 7x.
- Preço e % sempre reais (do que foi coletado).
- Emojis com moderação (1 por linha costuma bastar).
- Sem promessas falsas ("melhor do mundo") nem dado inventado.
